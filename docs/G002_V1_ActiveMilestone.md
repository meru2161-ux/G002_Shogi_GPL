# G002 将棋 — v2 Active Milestone

## 正式コンセプト

G002は、局面ごとの候補・盤上ガイド・理由を先生として伝える**指導モード**と、気軽に遊べる**AI対局モード**を同一アプリで提供する、オフライン学習将棋アプリである。

## Active Milestone

**G002 v2 Completion Candidate: ローカルAIによる連続対局・マンツーマン指導・終局導線の完成と品質確認**

外部USIエンジンは将来差し替え可能な抽象化のまま保持する。GPLv3候補およびSunfish4のdataはProduction APK/AABへ入れない。

## v2の実装方針

- `ShogiRules`を唯一の合法手生成源とする。UI・探索・AI応手はすべて同じ合法手を使う。
- `LocalShogiAnalysisEngine`は端末内の軽量Negamax / Alpha-Beta / Iterative Deepeningで候補3手とPVを作る。
- 評価は駒・持ち駒・成駒・王手・玉の危険・歩の前進・大駒/金銀の働きを一か所で扱う。
- `ShogiGameSession`が、着手、レビュー、AI応手、再解析、詰み、千日手、一手戻る、新局を一貫して管理する。
- Composeは局面IDごとの`LaunchedEffect`で解析する。局面変更・戻す・新局で古いcoroutineはキャンセルされ、局面IDまたは局面自体が一致しない結果は採用しない。

## v2で実装済みの利用者体験

1. モード選択（指導モード / AI対局モード）
2. 木目調の9×9盤、後手方向の駒、持ち駒、選択・合法手・前手・候補矢印表示
3. 駒タップ、移動、持ち駒打ち、成り/不成、非合法手拒否
4. 指導モードの候補3手、PV、意味、狙い、相手の応手、その後、注意点
5. ユーザー手の短い再探索による「良い手 / 自然な手 / 注意が必要な手 / 苦しくなりやすい手」の評価目安、勝ち筋方針、苦しくなる流れ、先生候補との比較
6. 相手AI応手、その狙い、新局面の再解析、質問UI（なぜ？ / 他の手は？ / 相手がこう指したら？ / 自分で考える）
7. 普通のAI対局、投了、新局、一手戻る、局面履歴、終局結果と新しい対局への導線
