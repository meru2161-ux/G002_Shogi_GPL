# Google Play 用アセット

| ファイル | 用途 | 仕様 | 状態 |
| --- | --- | --- | --- |
| `g002-play-icon-512.png` | ストアアイコン | 512 x 512, PNG, RGB | 提出用 |
| `g002-play-feature-1024x500.png` | フィーチャー画像 | 1024 x 500, PNG, RGB | 提出用 |
| `screenshots/g002-guidance-mode.png` | 指導モード画面 | 1080 x 2400, PNG, RGB | UI改善前の比較用 |
| `screenshots/g002-ai-match-mode.png` | AI対局モード画面 | 1080 x 2400, PNG, RGB | UI改善前の比較用 |

これらは G002 のために新規生成・調整した独自アセットです。既存アプリの画像やレイアウトをコピーしていません。

## スクリーンショット

`screenshots/` の2枚は、実行中のG002から取得した実画面ですが、2026-09-29のUI改善前です。最終ストア提出には改善後の実画面を新たに取得します。生成画像をアプリ画面として提出してはいけません。

公開版前に、次の2枚を追加すると説明力が上がります。

1. 成り選択または持ち駒を打つ画面
2. 終局結果カード
